关键词匹配

仅在启用「选择性」且填写排除 / 次要关键词时发挥作用。

整词匹配对中文、日文等不以空格分词的语言可能造成漏匹配；这类条目通常建议关闭。关键词支持使用 JavaScript 正则表达式格式，例如 /dragon/i，无需额外开关。

互斥分组

同组中多个条目同时触发时，通常只会选中其中一个。权重越高，被选中的相对机会越大；优先选择会按条目顺序确定胜出项。分组评分可继承全局设置或单独覆盖。

角色过滤

填写酒馆角色卡对应的头像文件名 / 标识，不是显示备注名。留空表示不限制角色。

关闭时仅允许名单中的角色；开启时名单中的角色会被排除。现阶段不编辑角色标签 ID，原有标签过滤数据会完整保留。

生成类型触发

不选择任何项目表示所有生成类型均可触发。Regenerate 在群聊中有酒馆自身的行为限制。

额外匹配来源

除聊天记录外，也可从角色卡或当前 Persona 的资料中匹配关键词。

递归控制

递归总开关与最大递归步数仍由酒馆全局设置控制；这里仅编辑单条目的递归行为。

插入出口 / Outlet

仅当插入位置选择 Outlet 时使用。在提示词可解析宏的位置通过 {{outlet::WORLD_LORE}} 调用。名称区分大小写；不要在世界书条目正文中嵌套 Outlet 宏。
